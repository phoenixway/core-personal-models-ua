## Мета артефакту

Цей артефакт містить
фінальний список головних орієнтирів,
які задають верхній рівень життєвого управління.

Він не містить:
- стратегію
- плани
- задачі
- проекти
- тижневі або денні дії

Він містить:
- сам список головних орієнтирів
- коротке розрізнення між ними
- посилання на профіль кожного орієнтиру
## Правила рівня

- тут тільки головне
- не більше 7 орієнтирів
- без дублювання
- без короткострокового
- без задач
- без розмитих красивих формул без змісту
- кожен орієнтир має окремий профіль
- якщо два орієнтири майже однакові → об’єднати або чітко розвести
