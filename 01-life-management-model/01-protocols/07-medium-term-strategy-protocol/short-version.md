# ⚙️ ПРОГРАМА ПЕРІОДУ — ПОЛЬОВА КАРТКА

1. Вибери, які головні орієнтири реально йдуть в роботу цього періоду.
2. Зафіксуй реальну пропускну здатність періоду: час, сили, складна робота.
3. Для кожного активного орієнтиру задай мінімально достатній результат на період.

```text
ГОЛОВНИЙ ОРІЄНТИР
→ МІНІМАЛЬНО ДОСТАТНЯ РЕАЛІЗАЦІЯ
````

4. Розклади кожен результат у backlog реальної роботи.
    
5. Грубо оціни backlog і перевір, чи він влазить у період.
    
6. Якщо не влазить — скороти результат, backlog або кількість активних орієнтирів.
    

```text
МІНІМАЛЬНО ДОСТАТНЯ РЕАЛІЗАЦІЯ
→ BACKLOG
→ ЧИ ВЛАЗИТЬ?
```

7. Збери backlog у завершені тижневі вузли.
    

```text
BACKLOG
→ WEEK ACTION UNITS
```

8. Для першого тижневого вузла виділи 1–3 перші дії.
    

```text
WEEK ACTION UNIT
→ FIRST DAY ACTION UNITS
```

9. Якщо немає first day action units — програма не готова.
    
10. Зафіксуй програму і передай у виконання.
