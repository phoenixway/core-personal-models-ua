# Чи потрібна деталізація моделі реалізації?

Деталізація потрібна тільки якщо:

- [ ] MVP-модель занадто груба і не дає передати орієнтир далі
- [ ] орієнтир складний або змішаний
- [ ] незрозуміло, чи потрібне стратегічне проектування
- [ ] є конфлікт між кількома механізмами реалізації
- [ ] незрозуміло, що вважати реальною реалізацією
- [ ] control показав дефект моделі реалізації

## Рішення

- [ ] MVP достатня → не деталізувати
- [ ] потрібна деталізація
