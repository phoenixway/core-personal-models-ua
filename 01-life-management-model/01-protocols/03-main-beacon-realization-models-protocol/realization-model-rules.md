# Правила моделей реалізації

1. Головний орієнтир ≠ модель його реалізації
2. Природа орієнтиру і тип реалізації — різні речі
3. Спочатку MVP, потім деталізація
4. Якщо MVP достатня → не деталізувати
5. Підтримуючий тип = повноцінний тип реалізації
6. Не всі орієнтири потребують стратегічного проектування
7. Кожен орієнтир має мати контур передачі далі
8. Не оптимізувати після freeze
