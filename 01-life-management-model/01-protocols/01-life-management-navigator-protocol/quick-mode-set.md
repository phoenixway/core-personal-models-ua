# Швидке визначення режиму

- немає ясності → **РОЗРОБКА КУРСУ** → Йди до [[04-course-development-mode]] (Розробка курсу і увімкнення рівнів управління життєдіяльністю)
- є ясність. краще всього - тактично-стратегічна. мінімум - тактична → **ВИКОНАННЯ** → Йди до [[01-execution-mode]] (Виконання)
- щось не працює або прийшов час обов'язкового огляду → **КОНТРОЛЬ** → Запусти [[05-control-mode]]
- випав з контексту → **ВІДНОВЛЕННЯ** → Відкрий Snapshot, не ламай систему [[02-recovery-mode]]
- перевантаження / криза → **КРИЗА** → Скинь усі плани до 1 Action Unit на день [[03-emergency-mode]]
## ПРАВИЛА

- один режим одночасно  
- вищий режим перекриває нижчий  
- EXECUTION тільки якщо система стабільна  

### CONTROL (ОБОВ’ЯЗКОВО)
👉 запускається:
- раз на тиждень
- або при відчутті проблем
### SYSTEM CLOCK

- **Щодня** → Execution (Дія) + Micro-Improve (1 Timebox)
- **Щотижня** → Control + План тижня
- **Щомісяця** → Програма + Стратегічний Review
- **Періодично** → Перегляд Орієнтирів та Факторів
