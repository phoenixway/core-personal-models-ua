# ОРІЄНТИР — КРАЩА ВЕРСІЯ ЖИТТЯ

Ця збірка описує орієнтир **«Краща версія життя»** як окремий верхній модуль системи.

Головна ідея:

- є **сокровенні орієнтири** — куди треба йти;
- є **екзоскелет життя** — як іти так, щоб не зійти з курсу;
- є **життєва програма мінімум** — сталеве ядро того, що треба тримати навіть у бурі;
- є **високий стандарт власних проявів** — окремий головний орієнтир, бо життя цінне не тільки тим, що з нього отримано, а й тим, що через мене в нього увійшло.

## Коротко

**Краща версія життя** тут розуміється не як фантастичний ідеальний сценарій, а як:

- внутрішньо валідний набір головних орієнтирів;
- порядок їх обов'язковості;
- працююча життєва програма;
- реальне життя в її логіці;
- незламний спосіб руху до сокровенного в наявних обставинах.
