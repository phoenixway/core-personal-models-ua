# APPLY TO EXECUTION — Застосування до реалізації

## Навіщо
Виконання може бути старанним, але слабким.
Тому треба перевіряти сам процес реалізації.

## Питання

### Сила виконання
- Чи саме це виконання варте часу?
- Чи це головне, а не втеча в легке?

### Якість виконання
- Є реальний прогрес?
- Є тертя / злив / тупцювання?
- Чи спосіб реалізації не є слабким?

### Управління реалізацією
- Чи не витрачається занадто багато ресурсу на контроль процесу?
- Чи не важчий management, ніж саме виконання?

### Переходи
- Чи є next step?
- Чи не зависає виконання між кроками?
- Чи не губиться імпульс після завершення вузлів?

## Можливі виходи
- спростити
- змінити спосіб
- уточнити next step
- повернутись до головного
- відсікти зайве
- перебудувати execution pattern
